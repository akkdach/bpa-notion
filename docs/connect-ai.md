# คู่มือเชื่อมต่อ AI เข้ากับ ProjectManagement

คู่มือนี้สำหรับ **ผู้ดูแลระบบ / เจ้าของ workspace** ที่ต้องการให้ Claude Code
เข้ามาอ่านและจัดการงานในระบบได้โดยตรง

ใช้เวลาประมาณ **10 นาที** ทำครั้งเดียวจบ

---

## เชื่อมต่อแล้วได้อะไร

AI จะทำงานกับข้อมูลในระบบได้จริง ไม่ใช่แค่คุยเรื่องงาน:

| AI ทำอะไรได้ | ตัวอย่างที่สั่งได้ |
|---|---|
| อ่านงาน | "สรุปงานที่ค้างอยู่ในโปรเจกต์ทั้งหมดให้หน่อย" |
| ค้นหา | "หาหน้าที่พูดถึงยอดขายไตรมาสสาม" |
| สร้างและจัดระเบียบงาน | "แตกงานนี้เป็นงานย่อย 5 อันตามขั้นตอนที่คุยกัน" |
| อัปเดตสถานะ | "ปิดงานที่ทำเสร็จแล้วทั้งหมดในโปรเจกต์นี้" |
| รายงานความคืบหน้า | "บันทึกสิ่งที่ตรวจเจอไว้ในหน้างานนั้น" |
| เขียนเนื้อหาลงหน้า | "เขียนสรุปการประชุมต่อท้ายหน้านี้" |

และ **คุณตรวจสอบทุกอย่างที่ AI ทำได้จากหน้าเว็บ** — ดูหัวข้อ
[ตรวจงานที่ AI ทำ](#ตรวจงานที่-ai-ทำ)

> **ตั้งค่า → สมาชิก** แล้วดูสิทธิ์ของตัวเองในรายการ

## ขั้นตอน

> ทุกคำสั่งในคู่มือนี้รันจาก **โฟลเดอร์หลักของโปรเจกต์** (โฟลเดอร์ที่มีไฟล์
> `README.md` และโฟลเดอร์ `api/` `web/` `mcp/` อยู่ข้างใน)

### 1. เปิดระบบทิ้งไว้ก่อน

ตัวเชื่อมต่อคุยกับระบบผ่าน API เดียวกับที่เว็บใช้ จึงต้องมีระบบรันอยู่

```bash
dotnet run --project api
```

ปล่อยหน้าต่างนี้ไว้ อย่าปิด แล้วเปิดหน้าต่างใหม่ทำขั้นถัดไป

> ถ้าคุณรันด้วย Docker (`docker compose up -d`) ระบบจะอยู่ที่
> `http://localhost:5080` ให้จำเลขนี้ไว้ใช้ในขั้นที่ 2

### 2. สร้าง token ในเว็บ

**เปิดเว็บ → เมนูมุมซ้ายบน → ตั้งค่า → การเชื่อมต่อ AI**

1. ตั้ง **ชื่อ token** ตามเครื่องที่จะใช้ เช่น *"โน้ตบุ๊กสมชาย"*
   — ไว้ให้รู้ว่าต้องเพิกถอนใบไหนถ้าเครื่องนั้นหาย
2. เลือก **วันหมดอายุ** (เลือก *ไม่มีวันหมดอายุ* ได้ถ้าเป็นเครื่องประจำ)
3. กด **สร้าง token**

จะได้ค่ายาว ๆ ขึ้นต้นด้วย `pmt_` กด **คัดลอก** ไว้

> ⚠️ **ค่านี้แสดงครั้งเดียว** ระบบเก็บไว้แค่ลายนิ้วมือของมัน ไม่ได้เก็บตัวค่า
> จึงไม่มีทางเปิดดูซ้ำได้ ถ้าทำหายให้กดสร้างใบใหม่แล้วเพิกถอนใบเก่าทิ้ง

การกดสร้างครั้งแรกจะทำให้ระบบสร้าง **บัญชีแยกสำหรับ AI** ให้อัตโนมัติ
(คุณไม่ต้องทำอะไร มันจะไปโผล่ใน *ตั้งค่า → สมาชิก* พร้อมป้าย 🤖 AI)

> **ทำไมต้องเป็นบัญชีแยก** — ถ้า AI ใช้บัญชีเดียวกับคุณ ประวัติการแก้ไขจะบอกว่า
> "คุณเป็นคนแก้" ทุกครั้ง แล้วคำถามว่า *"อันนี้ฉันทำเองหรือ AI ทำ"* จะตอบไม่ได้เลย

### 3. รันสคริปต์ตั้งค่า

```powershell
pwsh scripts/setup-mcp.ps1
```

สคริปต์จะถามสองข้อ:

| คำถาม | ตอบว่าอะไร |
|---|---|
| **URL ของ API** | กด Enter เพื่อใช้ค่าเริ่มต้น `http://localhost:5081`<br>(ถ้าใช้ Docker ให้พิมพ์ `http://localhost:5080`) |
| **วาง token ที่นี่** | วางค่าที่คัดลอกมาจากขั้นที่ 2 (วางแล้วจะไม่แสดงบนจอ) |

จากนั้นสคริปต์จะยิงคำขอทดสอบหนึ่งครั้งเพื่อยืนยันว่า token ใช้ได้จริง แล้วเก็บไว้ใน
ที่เก็บความลับของเครื่อง (นอกโปรเจกต์ ไม่ขึ้น git) — ถ้า token ผิดหรือหมดอายุ
คุณจะรู้ตรงนี้เลย ไม่ใช่ไปรู้ตอนสั่งงาน AI

### 4. เปิด Claude Code ใหม่

**ต้องปิดแล้วเปิดใหม่** — Claude Code อ่านรายการเครื่องมือตอนเริ่มทำงานเท่านั้น

เปิดในโฟลเดอร์ของโปรเจกต์นี้ (สำคัญ — เปิดผิดโฟลเดอร์จะไม่เห็นการเชื่อมต่อ)

เมื่อเปิดครั้งแรกจะมีข้อความถามว่าจะอนุญาตให้ใช้ตัวเชื่อมต่อชื่อ
`projectmanagement` หรือไม่ — ตอบอนุญาต

### 5. ตรวจว่าเชื่อมต่อสำเร็จ

พิมพ์ในหน้าต่าง Claude Code:

```
/mcp
```

ต้องเห็น `projectmanagement` สถานะ **connected**

จากนั้นลองสั่งงานจริง:

```
มีโปรเจกต์อะไรอยู่บ้าง
```

ถ้าตอบกลับมาเป็นรายการโปรเจกต์ในระบบ = ใช้ได้แล้ว

กลับไปดูที่ **ตั้งค่า → การเชื่อมต่อ AI** อีกครั้ง — ใบนั้นจะเปลี่ยนจาก
*"ยังไม่เคยถูกใช้"* เป็น *"ใช้ล่าสุด เมื่อสักครู่"* ซึ่งเป็นการยืนยันจากฝั่งระบบว่า
เครื่องนั้นต่อเข้ามาได้จริง

## ตรวจงานที่ AI ทำ

ทุกอย่างที่ AI ทำถูกบันทึกไว้และดูย้อนหลังได้จากหน้าเว็บ

**เปิดเว็บ → ปุ่ม "ตรวจงาน" ที่มุมซ้ายล่าง**

| แท็บ | ใช้ดูอะไร |
|---|---|
| **บอร์ดงาน** | งานทั้งหมดแยกตามสถานะ ยังไม่เริ่ม / กำลังทำ / เสร็จแล้ว |
| **ใครทำอะไร** | รายการทุกการเปลี่ยนแปลง เรียงจากใหม่ไปเก่า |

ในแท็บ **ใครทำอะไร** กรองได้ว่าจะดูเฉพาะสิ่งที่ AI ทำ (🤖) หรือเฉพาะที่คนทำ (👤)
และถ้า AI เปลี่ยนสถานะงานผิด กด **ย้อนกลับ** ได้ทันที

จุดอื่นที่เห็นร่องรอยของ AI:

- **แถบด้านซ้าย** — สัญลักษณ์สถานะข้างชื่อหน้า (⬜ 🔄 ✅) กดเปลี่ยนได้เลย
- **ใต้เอกสารแต่ละหน้า** — แผงบันทึกความคืบหน้า ข้อความที่ AI เขียนมีป้าย 🤖
  และคุณเขียนตอบกลับได้ในช่องเดียวกัน
- **ตั้งค่า → สมาชิก** — บัญชีของ AI มีป้าย 🤖 AI กำกับไว้
- **ถังขยะ** — หน้าที่ถูกลบกู้คืนได้ (AI ลบถาวรไม่ได้ ดูหัวข้อถัดไป)

## ขอบเขตและความปลอดภัย

### AI เห็นอะไรได้บ้าง

AI เห็นและแก้ได้ **เท่าที่บัญชีของมันเห็นและแก้ได้** ไม่มีสิทธิ์พิเศษใด ๆ
มันเป็นสมาชิกคนหนึ่งใน workspace ที่คุณเลือกเท่านั้น

- **workspace อื่น — มองไม่เห็นเลย** token หนึ่งใบผูกกับ workspace ที่ออกให้เท่านั้น
  และขอบเขตนี้บังคับที่ฝั่งเซิร์ฟเวอร์ ไม่ใช่ค่าที่แก้ได้จากฝั่งเครื่องคุณ
- ต่อหนึ่ง token AI เข้าถึงได้ **หนึ่ง workspace** จะให้ช่วยงานอีก workspace
  ต้องเข้าไปสร้าง token ใบใหม่ที่นั่น

### สิ่งที่ AI ทำไม่ได้

| ทำไม่ได้ | ทำไม |
|---|---|
| **ลบถาวร** | ตั้งใจไม่เปิดให้ — AI ลบได้แค่ย้ายลงถังขยะ ซึ่งคุณกู้คืนได้เสมอ |
| ลบหรือแก้เนื้อหาเดิมในหน้า | เขียนได้แต่ **ต่อท้าย** เท่านั้น ของเดิมไม่ถูกแตะ |
| ลบบันทึกที่เขียนไปแล้ว | บันทึกแก้ย้อนหลังไม่ได้ เขียนผิดต้องเขียนใหม่ต่อท้าย |
| จัดการสมาชิก / เปลี่ยนสิทธิ์ | ยังไม่เปิดให้ |
| เปลี่ยนตัวเองเป็นบัญชีของคน | ต้องให้ owner หรือ admin เป็นคนกำหนดเท่านั้น |

### อยากจำกัดขอบเขตให้แคบลง

**AI เห็นทุกหน้าใน workspace ที่มันเป็นสมาชิก** — ตอนนี้ยังไม่มีหน้าจอสำหรับ
กำหนดสิทธิ์รายหน้า (อยู่ในแผนพัฒนา) ดังนั้นถ้ามีข้อมูลที่ไม่ควรให้ AI เห็น
**วิธีที่ได้ผลจริงตอนนี้คือแยก workspace**

1. สร้าง workspace ใหม่สำหรับงานที่ต้องการให้ AI ช่วย
2. ย้ายหรือสร้างเฉพาะหน้าที่เกี่ยวข้องไว้ที่นั่น
3. สร้าง token ใน workspace นั้น แล้วรัน `pwsh scripts/setup-mcp.ps1` ใหม่

ข้อมูลใน workspace อื่นจะมองไม่เห็นเลย ไม่ใช่แค่ถูกซ่อน

> ⚠️ **อย่าลดสิทธิ์บัญชี AI ลงเป็น guest เพื่อหวังจำกัดขอบเขต** — guest สร้างหน้า
> ระดับบนสุดไม่ได้ AI จะพยายามซ้ำ ๆ แล้วไม่จบ ให้คงไว้ที่ *member* เสมอ

### ยกเลิกการเชื่อมต่อ

เปิดเว็บ → **ตั้งค่า → การเชื่อมต่อ AI** → กด **เพิกถอน** ที่ใบนั้น

มีผลกับคำขอถัดไปทันที ไม่ต้องรอวันหมดอายุ และไม่ต้องเข้าไปแก้อะไรที่เครื่องปลายทาง
— เครื่องนั้นจะเข้าไม่ได้อีกแม้ยังถือค่า token อยู่

เพิกถอนได้ทีละใบ เครื่องอื่นที่ยังใช้อยู่ไม่ได้รับผลกระทบ ถ้าจะตัดขาดทั้งหมดจริง ๆ
ให้เพิกถอนทุกใบ หรือถอดบัญชีที่มีป้าย 🤖 AI ออกจาก workspace ใน *ตั้งค่า → สมาชิก*

## ข้อจำกัดที่ควรรู้ก่อนใช้งานจริง

**AI อาจเห็นเนื้อหาหน้าไม่ครบในบางกรณี**

ระบบเก็บเนื้อหาหน้าในรูปแบบที่ออกแบบมาให้แก้ไขพร้อมกันหลายคนได้ ซึ่งเซิร์ฟเวอร์
อ่านตรง ๆ ไม่ได้ ตัวข้อความที่ AI อ่านจึงเป็นสำเนาที่เบราว์เซอร์ส่งกลับมาให้
ผลที่ตามมา:

- **หน้าที่ยังไม่เคยมีใครเปิดในเบราว์เซอร์** — AI จะรายงานว่า *"ยังไม่มีข้อมูล"*
  ซึ่งไม่ได้แปลว่าหน้านั้นว่าง เปิดหน้านั้นในเว็บสักครั้งแล้วข้อความจะมา
- **หน้าที่เพิ่งแก้สด ๆ** — ข้อความอาจช้ากว่าของจริงประมาณ 2 วินาที
- **หน้าที่แก้ตอนเน็ตหลุด** — ข้อความจะยังไม่อัปเดตจนกว่าจะเปิดหน้านั้นอีกครั้ง

**AI เขียนได้เฉพาะย่อหน้าธรรมดา**

ไม่มีหัวข้อ รายการหัวข้อย่อย ตาราง หรือตัวหนา/เอียง — เป็นข้อจำกัดที่ตั้งใจ
เพื่อไม่ให้การเขียนจากฝั่งเซิร์ฟเวอร์ไปทำเนื้อหาของคุณเสียหาย

ถ้าต้องการให้ AI รายงานอะไรที่ไม่ควรปนกับเอกสาร ให้สั่งว่า **"บันทึกไว้"**
มันจะเขียนลงแผงบันทึกใต้เอกสารแทน ซึ่งแยกจากงานของคุณชัดเจน

## แก้ปัญหา

| อาการ | สาเหตุและวิธีแก้ |
|---|---|
| `/mcp` ไม่ขึ้น `projectmanagement` เลย | เปิด Claude Code ผิดโฟลเดอร์ — ต้องเปิดในโฟลเดอร์โปรเจกต์นี้ |
| `/mcp` ขึ้นสถานะ **failed** | ยังไม่ได้รันสคริปต์ตั้งค่า → `pwsh scripts/setup-mcp.ps1` |
| AI ตอบว่า *"ต่อ API ไม่ได้ที่ …"* | ระบบไม่ได้รันอยู่ → เปิด `dotnet run --project api` ทิ้งไว้<br>หรือ URL ผิด (ปกติ 5081 · Docker 5080) |
| AI ตอบว่า *"ยังไม่ได้ตั้ง Pm:Token"* | ยังไม่ได้รันสคริปต์ตั้งค่า หรือรันจากโฟลเดอร์อื่น |
| AI ตอบว่า *"ระบบเปลี่ยนมาใช้ API token แล้ว"* | ค่าเก่าจากรุ่นก่อนค้างอยู่ — สร้าง token แล้วรัน `pwsh scripts/setup-mcp.ps1` ใหม่ มันลบค่าเก่าให้เอง |
| AI ตอบว่า *"API 401"* ทุกคำสั่ง | token ถูกเพิกถอนหรือหมดอายุ — ดูสถานะที่ **ตั้งค่า → การเชื่อมต่อ AI** แล้วออกใบใหม่ |
| สคริปต์บอกว่า *"ค่านี้ไม่ใช่ API token ของระบบนี้"* | วางผิดค่า — ต้องขึ้นต้นด้วย `pmt_` และมาจากหน้า **การเชื่อมต่อ AI** เท่านั้น |
| สคริปต์บอกว่า *"ใช้ token นี้ไม่ได้"* | ระบบไม่ได้รันอยู่ · URL ผิด port · หรือ token ถูกเพิกถอนไปแล้ว |
| ไม่เห็นหัวข้อ **การเชื่อมต่อ AI** ในหน้าตั้งค่า | ต้องเป็น owner หรือ admin — ให้ owner สร้าง token ให้แล้วส่งมาให้ |
| AI มองไม่เห็นหน้าที่เพิ่งสร้าง | เปิดหน้านั้นในเว็บสักครั้ง (ดูหัวข้อข้อจำกัดด้านบน) |
| เปลี่ยน workspace ที่ให้ AI เข้าถึง | สร้าง token ใน workspace นั้น → รัน `pwsh scripts/setup-mcp.ps1` ใหม่ → เปิด Claude Code ใหม่ |

รันสคริปต์ตั้งค่าซ้ำได้เสมอ — กด Enter ผ่านช่อง token ถ้าจะใช้ใบเดิม

## คำถามที่พบบ่อย

**ข้อมูลของเราถูกส่งออกไปข้างนอกไหม**
ตัวเชื่อมต่อทำงานบนเครื่องคุณและคุยกับระบบของคุณเองเท่านั้น ส่วนข้อความที่คุณ
สนทนากับ Claude เป็นไปตามนโยบายของ Claude Code ตามปกติ — เหมือนตอนให้มันอ่านโค้ด

**ต้องตั้งค่าใหม่ทุกครั้งที่เปิดเครื่องไหม**
ไม่ต้อง ตั้งครั้งเดียวจบ แค่ต้องมีระบบ (`dotnet run --project api`) รันอยู่ตอนใช้งาน

**หลายคนในทีมใช้พร้อมกันได้ไหม**
ได้ **ออก token คนละใบให้แต่ละเครื่อง** แล้วให้แต่ละคนทำตามขั้นที่ 3–5 บนเครื่องตัวเอง

อย่าใช้ใบเดียวกันหลายเครื่อง — ไม่ใช่เพราะระบบห้าม แต่เพราะพอใช้ร่วมกันแล้วคุณจะ
ไม่รู้ว่า *"ใช้ล่าสุด"* มาจากเครื่องไหน และวันที่เครื่องหนึ่งหาย คุณจะเพิกถอนไม่ได้
โดยไม่ตัดคนอื่นไปด้วย ใบละเครื่องทำให้ทั้งสองอย่างนี้ทำได้

> ทุกใบผูกกับบัญชี AI เดียวกันของ workspace นั้น ประวัติจึงบอกว่า "AI ทำ" เหมือนกันหมด
> ไม่ได้แยกว่าเป็น AI ของใคร — ถ้าต้องการแยกระดับนั้นให้แจ้งผู้พัฒนา

**ต้องต่ออายุ token ไหม**
ถ้าเลือก *ไม่มีวันหมดอายุ* ก็ไม่ต้อง ถ้าตั้งวันหมดอายุไว้ พอถึงวันนั้นใบจะขึ้นสถานะ
*หมดอายุ* ในหน้าตั้งค่า และ AI จะตอบว่า `API 401` — สร้างใบใหม่แล้วรัน
`pwsh scripts/setup-mcp.ps1` อีกครั้ง

**AI แก้งานผิดจะกู้คืนอย่างไร**
เปลี่ยนสถานะผิด → หน้า **ตรวจงาน → ใครทำอะไร** กด *ย้อนกลับ*
ลบหน้าผิด → **ถังขยะ** กด *กู้คืน*
เขียนเนื้อหาผิด → เปิดหน้านั้นแล้วลบย่อหน้าที่ไม่ต้องการเหมือนแก้เอกสารปกติ
